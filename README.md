## 关于此仓库

此仓库是 **mantoujun-lab** 组织的主要展示网站源代码，使用 Vercel 部署
访问地址：[https://www.mantoujun-lab.com](https://www.mantoujun-lab.com)

## 开发

本项目使用 [Bun](https://bun.sh) 作为包管理器，请先安装 Bun。

```bash
bun install        # 安装依赖
bun run dev        # 启动开发服务器
bun run build      # 构建生产版本
bun run preview    # 本地预览构建结果
```
